# AWA

- `mobile/` — the React Native application (see [mobile/README.md](mobile/README.md) for setup/run instructions).
- `web/` — future landing page / admin (not yet started).
- `backend/` — future API/server (not yet started).

Run all mobile commands (`npm install`, `npm start`, `npx react-native run-android`, `npx tsc --noEmit`, `npx jest`, etc.) from `mobile/`, not from the repository root.
